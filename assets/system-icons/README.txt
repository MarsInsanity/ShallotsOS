TreeFrogUI Cosy system icons

Created by KyleBing for the Cosy OnionOS theme.
License: GNU GPL v3
Source: https://github.com/KyleBing/retro-game-console-icons
Theme: https://github.com/KyleBing/onion-theme-cosy

Files are resized and named after TreeFrogUI ROM folders. Optional icon packs
can override an icon with <folder>.png; the shared icon is used as fallback.

scummvm.png and scummvm.svg are original TreeFrogUI artwork.
