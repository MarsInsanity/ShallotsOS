# PocketStation (Pokket)

Put PocketStation content in `roms/pokket/`. Pokket accepts memory-card images
(`.mcd`, `.gme`) and individual save/title-sector files (`.mcs`, `.pss`, `.bin`).
The `.bin` extension is ambiguous in the general file picker, so use the
`pokket` folder to select those files reliably.

Pokket requires a legally obtained PocketStation BIOS named exactly
`pocketstation.bin`. Put it at `cubegm/bios/pocketstation.bin` on the SD card.
The release does not include this BIOS.
