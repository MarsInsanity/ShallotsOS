# FroggyReader (EPUB)

← [back to README](../../README.md)

FroggyReader is an alternative EPUB reader available from **Apps → FroggyReader
(EPUB)**. Selecting it opens the book library directly. Put DRM-free `.epub`
books in **`roms/epub/books/`**. The library contains EPUBs only; the reader
does not support PDF, MOBI, or other formats.

FroggyReader is a Libretro core by [Synaps33](https://github.com/Synaps33),
based on the [FroggyReader project](https://github.com/Synaps33/FroggyReader).
Its settings and reading position are stored in
`/mnt/sdcard/picoarch/epub/epub_reader/reader.cfg`. PicoArch save states are
not supported by this core.

See the [save files and save states guide](save-files.md) for the paths used by
other systems and the standalone Ebook reader.
